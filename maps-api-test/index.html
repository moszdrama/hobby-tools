💡 ข้อผิดพลาดที่พบบ่อย (Common Errors & Fixes)

⚠️ API Not Activated

คุณต้องเปิดใช้งาน Maps JavaScript API ใน Google Cloud Console (APIs & Services > Enabled APIs & Services > + ENABLE APIS AND SERVICES).

🔒 Website / Referrer Restriction

หากตั้งค่า Application restrictions (HTTP referrers) ต้องแน่ใจว่าได้ระบุ URL หรือโดเมนที่กำลังรันอยู่ (เช่น http://localhost:* หรือ file://*)

💳 Billing Not Enabled

โปรเจกต์ Google Cloud จำเป็นต้องผูกบัญชี Billing (แม้จะมีเครดิตฟรี $200 ต่อเดือนก็ตาม) มิเช่นนั้น Google จะปฏิเสธการเรียกใช้ API

❌ Invalid Key / Expired

API Key สะกดผิด ถูกลบ หรือมีช่องว่างเกินมา ให้ตรวจสอบและคัดลอกใหม่อีกครั้งจาก Credentials
